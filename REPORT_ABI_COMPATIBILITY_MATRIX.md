## Version-dispatch design (what "official path" means)

There is no single auto-dispatching parser. Each Replay ABI version has its own parser module, and
each replay entrypoint hardcodes the parser for the version it targets:

| ABI | parser module | entrypoint(s) |
| --- | --- | --- |
| v0 (Reno) | `user/ccr_trace.py` — `parse_trace` / `validate_run` | `user/replay_r1.py`, `user/replay_r2.py` |
| v1 (CUBIC) | `user/ccr_trace_v1.py` — `parse_trace_v1` / `validate_run_v1` | `user/replay_r3a.py`, `user/replay_r3b.py` |
| v2 (CoVegas) | `user/ccr_trace_v2.py` — `parse_trace_v2` / `validate_run_v2` | `user/replay_e2.py`, `user/replay_e3.py` |
| v0 + v1 | `user/ccreplay_diff.py` — `_detect_version_and_parse` peeks `magic`+`trace_version` from the 144-byte header and dispatches to the v0 or v1 parser; **v2 → `ValueError("unsupported trace_version 2")`** | `user/ccreplay_diff.py`, `user/ccreplay_checkpoint.py` |

Each `parse_trace*` reads the common `TraceHeader` (144 B, identical across versions), then:
`magic != CCR_TRACE_MAGIC` → `TraceValidationError`; `trace_version != <this parser's version>` →
`TraceValidationError("unknown trace_version …")`; `record_size != EVENT_SIZE` →
`TraceValidationError("record_size mismatch")`.

## Matrix (real trace of each version fed to each boundary)

Traces: `raw/r0/rep1.ccr` (v0, 37,260 events), `raw/cubic_replay/primary/rep1.ccr` (v1, 78,690),
`raw/covegas_replay/primary/rep1.ccr` (v2, 63,330).

| boundary | v0 trace | v1 trace | v2 trace |
| --- | --- | --- | --- |
| `ccr_trace.parse_trace` (v0) | **ACCEPTED_CORRECTLY** | REJECTED_CLEANLY (`unknown trace_version 1`) | REJECTED_CLEANLY (`unknown trace_version 2`) |
| `ccr_trace_v1.parse_trace_v1` (v1) | REJECTED_CLEANLY (`unknown trace_version 0`) | **ACCEPTED_CORRECTLY** | REJECTED_CLEANLY (`unknown trace_version 2`) |
| `ccr_trace_v2.parse_trace_v2` (v2) | REJECTED_CLEANLY (`unknown trace_version 0`) | REJECTED_CLEANLY (`unknown trace_version 1`) | **ACCEPTED_CORRECTLY** |
| `ccreplay_diff._detect_version_and_parse` | **ACCEPTED_CORRECTLY** | **ACCEPTED_CORRECTLY** | REJECTED_CLEANLY (`ValueError: unsupported trace_version 2`) |
| `validate_run` / `_v1` / `_v2` (own version) | **ACCEPTED_CORRECTLY** (`pass=True`) | **ACCEPTED_CORRECTLY** (`pass=True`) | **ACCEPTED_CORRECTLY** (`pass=True`) |

Foreign-version cells for the version-specific validation entrypoints are `NOT_APPLICABLE` by
construction (each `validate_run*` calls its own `parse_trace*`, which raises first — covered by the
parser rows above).

**`MISPARSED` cells: 0.** No boundary accepted a foreign-version trace, produced data for one, or
crashed with an unexpected exception. Every foreign-version rejection is the parser's own declared
`TraceValidationError` / `ValueError`, not a stack trace.
